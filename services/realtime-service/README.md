# Realtime Service (Go)

Подготовленная основа для будущего Go-сервиса realtime-взаимодействия Tandem. Сейчас здесь намеренно нет исполняемого кода, API, сетевых обработчиков, моделей или зависимостей.

## Планируемая ответственность

- WebSocket соединения и их жизненный цикл;
- онлайн-доска и события в реальном времени;
- presence участников занятий;
- взаимодействие с Java Core для будущей проверки доступа.

LiveKit остаётся ответственным за аудио- и видеосвязь. Бизнес-логика и постоянные бизнес-данные остаются в Java Core.

Назначение каталогов:

- `cmd/server/` — будущая точка входа;
- `internal/config/` — внутренняя конфигурация;
- `internal/handler/` — будущие транспортные обработчики;
- `internal/service/` — сценарии realtime-сервиса;
- `internal/repository/` — доступ к собственным данным, если он понадобится;
- `internal/websocket/` — управление WebSocket соединениями;
- `internal/model/` — внутренние типы сервиса;
- `pkg/` — только при появлении типов, которые действительно нужно публиковать другим Go-модулям.

Взаимодействие с Core и конкретные контракты пока не определены. См. [общую архитектуру](../../ARCHITECTURE.md).
