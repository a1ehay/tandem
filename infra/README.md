# Infrastructure configuration

Здесь зарезервировано место для будущей инфраструктурной конфигурации:

- `compose/` — Compose-файлы, если инфраструктуру потребуется разделить;
- `docker/` — Dockerfile новых сервисов;
- `env/` — шаблоны конфигурации окружений без секретов;
- `redis/` — конфигурация Redis, только если он станет необходим.

Существующие `compose.yaml`, `.env.example` и `database/Dockerfile` остаются источниками истины и не копируются сюда. Новые сервисы сейчас не добавлены.
