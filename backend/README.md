# Tandem Go backend

Минимальный самостоятельный HTTP-сервис на стандартной библиотеке Go. Пока содержит только проверку доступности; frontend build и Cloudflare Worker запускаются отдельно.

## Требования

Go 1.22 или новее. Дополнительные зависимости не нужны.

## Запуск

Из каталога `backend`:

```sh
HTTP_ADDR=:8080 go run ./cmd/tandem-api
```

`HTTP_ADDR` задаёт адрес прослушивания в формате `host:port`; значение по умолчанию — `:8080`. Файл `.env.example` документирует переменные; сервер читает окружение и не загружает env-файл автоматически.

Проверка:

```sh
curl http://localhost:8080/healthz
```

Успешный `GET /healthz` возвращает HTTP 200 и `{"status":"ok"}`. Другие методы для этого пути возвращают HTTP 405.
