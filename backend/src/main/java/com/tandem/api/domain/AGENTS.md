# Domain rules

- Domain содержит бизнес-понятия и инварианты Tandem и должен быть независим от Spring, web, Hibernate/JPA, JDBC и внешних SDK.
- Выражать состояния и бизнес-правила типами и методами домена, а не разрозненными строками и условными проверками по слоям.
- Не переносить в домен HTTP DTO, SQL-модели, persistence annotations или детали таблиц.
- Разделять сущность с идентичностью, value object и DTO; не создавать обобщённую модель только ради повторного использования полей.
- Держать инварианты рядом с соответствующей моделью, если они не требуют внешнего состояния; правила, требующие нескольких агрегатов или ресурсов, размещать в application service.
