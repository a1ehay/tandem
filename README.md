# Tandem — демо-платформа для репетиторов

Адаптивный браузерный прототип без сторонних библиотек и этапа установки зависимостей. В нём можно посмотреть интерфейс личных кабинетов, доски, занятий и планера. Это публичное демо, а не готовый сервис для работы с реальными учениками.

## Запуск на компьютере

Откройте PowerShell в папке проекта и выполните:

```powershell
py -m http.server 8000
```

Откройте <http://localhost:8000>. Если команда `py` недоступна, запустите `python -m http.server 8000`. Камера, микрофон и захват экрана доступны через localhost или защищённый HTTPS-сайт; браузер запросит разрешение после нажатия соответствующей кнопки.

## Структура проекта

- `frontend/src/client/` — клиентские ES-модули: состояние и локальное хранение, общие утилиты, шаблоны экранов, формы, геометрия доски и видеокомната.
- `frontend/` — исходники статического сайта и точка входа браузерного приложения.
- `cloudflare/worker.js` и `cloudflare/livekit-token.js` — маршрутизация Cloudflare Worker и выпуск временных токенов LiveKit.
- `backend/` — независимый Java/Spring Boot API на Java 25 LTS. Инструкции запуска — в [backend/README.md](backend/README.md).
- `database/` — отдельный Java/Maven-проект миграций PostgreSQL с Flyway; инструкции запуска — в [database/README.md](database/README.md), проект схемы — в [docs/database/database.md](docs/database/database.md).
- `compose.yaml` — единый Compose для PostgreSQL; переменные описаны в `.env.example`, а значения для каждого окружения задаются в локальном `.env` или в секретах production-сервера.
## Сборка сайта для публикации

Установите Node.js, если он ещё не установлен, затем из папки проекта выполните:

```powershell
node .\build.mjs
```

Готовые файлы окажутся в `dist`. Сборка переносит только нужные файлы сайта. Архивы и рабочие материалы из корня проекта не попадут в публикацию.

## Публикация через Cloudflare Workers

1. Создайте GitHub-репозиторий и загрузите в него файлы проекта.
2. В Cloudflare откройте **Workers & Pages → tandem → Settings → Builds** и подключите GitHub-репозиторий, если он ещё не подключён.
3. Укажите **Build command — `node build.mjs`**, **Deploy command — `npx wrangler deploy`**, **Root directory — `/`**. Папка `dist` и Worker с API-маршрутом задаются в `wrangler.jsonc`.
4. Сохраните настройки и дождитесь статуса **Ready**. Worker будет обновляться после коммитов в production-ветку.

Проект не устанавливает npm-зависимости для сборки. Файл `build.mjs` собирает статические файлы в `dist`. `wrangler.jsonc` настраивает Cloudflare Worker, который раздаёт сайт и обрабатывает серверный маршрут `/api/livekit/token`. Секреты LiveKit Worker читает только во время запроса; локальный `.dev.vars` исключён из Git.

## Что работает в демо

- Навигация по разделам и адаптивная компоновка.
- Тестовая видеокомната LiveKit с передачей камеры, микрофона и демонстрации экрана другим участникам после подключения обоих к одной комнате.
- Объектная доска: рисунки, стирание целого элемента, прямые линии с Shift, фигуры, текст, стикеры, перемещение, цвет, толщина, отмена и экспорт PNG.
- Доски можно связывать с занятиями и продолжать использовать в других занятиях.
- Блочный планер, личные задачи и домашняя работа.
- Локальные демо-профили ученика и репетитора; один ученик может быть связан с несколькими репетиторами.
- Переключение Light и Extreme в демо-режиме.

Профили и данные сохраняются в `localStorage` текущего браузера. У каждого браузера собственное локальное состояние; участники не видят изменения друг друга.

## Перед использованием с реальными учениками

На сайте намеренно показано предупреждение о демо-режиме. Не вводите настоящие персональные данные: профили и введённая информация хранятся только в браузере. Вход и роли также демонстрационные; нет настоящей регистрации, паролей, Google OAuth, синхронизации доски, общей базы данных и платежей. Перед тестовым звонком оба участника должны выбрать одно занятие, подключиться в его комнате и ввести общий временный код.

Для тестовых звонков Worker использует runtime secrets `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`, `LIVEKIT_DEMO_ROOM_CODE` и переменную `LIVEKIT_URL`. API Secret хранится только на сервере. Общий код комнаты — временная защита демо, он не заменяет аккаунты и проверку прав участников. Чтобы превратить прототип в рабочую платформу, понадобятся настоящая серверная авторизация и база данных, ограничение доступа к комнатам по занятию, синхронизация доски в реальном времени, платёжный провайдер, а также правила обработки данных и условия использования. Не публикуйте текущую демо-версию как готовый платный сервис.

Индексация поисковиками отключена (`noindex` и `robots.txt`), пока сайт остаётся демо-версией.
